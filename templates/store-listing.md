# 上架物料模板（应用名 / 简介 / 介绍 / 截图 / 图标）

> 规格来源：华为应用市场「应用素材规范」与 AGC 发布页提示（2026-10 口径）。
> 平台规则会调整，提交前以 AGC 页面上的实时提示为准。

---

## 1. 应用名称

- 上限：**15 个汉字**或 **30 个其他语言字符**
- 与《计算机软件著作权登记证书》上的软件名称/简称保持一致
- 不要用「倒计时」「计时器」「清理大师」这类广义归纳词，识别度低且容易被判名称不规范
- 包名（bundleName）与应用名称是两件事；包名在 AGC 创建后不可修改

填写：

```
应用名称：【不超过 15 个汉字】
```

---

## 2. 一句话简介

- 上限：**80 个字符**（官方建议不超过 **25 个字符**，列表页展示更完整）
- 写「给谁 + 解决什么」，不要堆关键词

填写：

```
主选（≤15 字）：【  】
备选 A（≤22 字）：【  】
备选 B（≤18 字）：【  】
```

---

## 3. 详细描述（应用介绍）

- 上限：**8000 字**；建议 **400–600 字**，手机端阅读节奏更好
- 结构建议：一句话定位 → 3–5 个功能点（每点一个小标题）→ 隐私/离线说明 → 适合谁
- 功能点用 `■` 或 `·` 开头，比大段文字更容易扫读
- 不要写「点击下载」「扫码」「加群」等诱导文案，也不要放联系方式的营销引导

模板：

```
【应用名称】，是【一句话比喻式定位】。

■ 【功能点 1：用户第一眼看到什么】
【两句话说明，写具体数字/动作，不写"智能""高效"这类空词】

■ 【功能点 2：核心差异】
【说明与同类应用的差别】

■ 【功能点 3：细节】
- 【细节 1】
- 【细节 2】

■ 不用注册，也不会联网
本应用不申请任何权限、没有账号、没有网络请求，所有数据只存在你设备里的
应用沙箱。卸载即清空。

适合谁：【目标用户一句话】。
```

## 4. 截图

### 4.1 规格（已核实）

| 项 | 要求 |
| --- | --- |
| 数量 | 手机竖向 **3–10 张** |
| 比例 | **9:16** |
| 分辨率 | **1080×1920** |
| 格式 | PNG / JPG / JPEG，单张 **≤ 5 MB**，不允许动图 |
| 平板 | 竖向 **2:3**、1280×1920，单独在平板页签上传 |

> 同一设备的介绍视频与截图方向需一致；不要加设备外框、水印、诱导文案。

### 4.2 生产流程

```bash
# 1) 抓原始截图（模拟器/真机）
bash screenshots/capture-emulator.sh -o screenshots/raw -p 01_home

# 2) 批量转成 1080×1920（等比缩放 + 左右补边，不裁切内容）
python3 screenshots/make-store-shots.py screenshots/raw -o screenshots/store
```

补边方式说明见 `screenshots/make-store-shots.py` 顶部注释：
源图通常比 9:16 更长，直接裁会切掉状态栏/导航栏，因此按高度等比缩放后左右补边；
`--pad edge` 用边缘像素拉伸（推荐），`--pad solid --bg "#0B0C10"` 用纯色填充。

### 4.3 建议的 5 张内容

1. 首页/主功能（第一眼价值）
2. 核心功能的另一种状态（如进行中、结果页）
3. 统计/记录页
4. 设置页
5. 特色交互（锁定、切换、导出等）

## 5. 应用图标

| 项 | 要求 |
| --- | --- |
| 数量 | 1 张 |
| 尺寸 | **216×216 或 1024×1024**，正方形 |
| 格式 | PNG，**≤ 3 MB** |
| 分层图标 | HarmonyOS 推荐前景 + 背景两层、1024×1024，**不要自己做圆角**（系统加遮罩），背景层不允许透明像素 |

工程内需要同步替换三处（AppScope 与 entry 各一份，启动图一份）：

```bash
cp assets/icon/app_icon_512.png AppScope/resources/base/media/app_icon.png
cp assets/icon/app_icon_512.png entry/src/main/resources/base/media/app_icon.png
cp assets/icon/app_icon_512.png entry/src/main/resources/base/media/startIcon.png
```

## 6. 分类与标签

| 项 | 建议 |
| --- | --- |
| 一级分类 | 与核心功能一致（工具类不要选社交/办公套件） |
| 二级分类 | 以 AGC 下拉里实际存在的选项为准 |
| 标签 | 3–5 个，覆盖功能词 + 场景词，不要堆无关热词 |

> 分类与标签不匹配会触发 AGC 的校验报错，提交前先在页面上确认能保存。
